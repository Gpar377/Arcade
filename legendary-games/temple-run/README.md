# Temple Run Game

A simple Temple Run-style endless runner game built with Python and Pygame.

## Features
- 3-lane running system
- Jump mechanics
- Obstacle avoidance
- Coin collection
- Score tracking
- Distance counter

## Controls
- **SPACE**: Jump
- **LEFT/A**: Move to left lane
- **RIGHT/D**: Move to right lane
- **R**: Restart game (when game over)

## Installation
1. Install Python 3.6+
2. Install pygame: `pip install pygame`
3. Run the game: `python temple_run.py`

## Gameplay
- Avoid red obstacles by jumping or changing lanes
- Collect golden coins to increase your score
- Try to run as far as possible!
- Game ends when you hit an obstacle
